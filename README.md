# Early-Detection-and-Tracking-of-Pneumonia-Using-Deep-learning
Early Detection and Tracking of Pneumonia Using Deep Learning is an AI-based project that analyzes chest X-rays to detect pneumonia quickly and accurately. It uses deep learning models like CNN/EfficientNet for early diagnosis and tracks patient records, helping doctors improve treatment and healthcare management.
